# StitchEdit — NeurIPS 2026

- WildActor style (main project address): https://guoqincode.github.io/StitchEdit/
- UniGP style: https://guoqincode.github.io/StitchEdit/unigp/
- Paper: https://openreview.net/forum?id=Q7G74v5nSs

Authors: Qin Guo and Dan Xu (corresponding author), HKUST.

Both layouts directly adapt the authors' previous research-project templates and use the same scientific content. WildActor uses a 960px content column and places comparisons before the abstract; UniGP uses a wider 1176px figure area and places the abstract before comparisons.

Desktop comparisons use one aligned row of shared method labels. Mobile comparisons show each label above its image. All images retain their full aspect ratio and link to the source-resolution asset. No sliders, tabs, sidebar, or fixed navigation are used. The Code button has no URL and remains disabled. BibTeX can be copied.

The abstract, method figure, and Table 1 come from the manuscript. The six qualitative comparisons use supplied evaluation images. The two styles share assets/, vendor/, app.js, and cases.json. No build step or external CDN is required. No camera-ready or poster review downloads are exposed by these pages.

# StitchEdit — NeurIPS 2026

Project page: https://guoqincode.github.io/StitchEdit/
Paper: https://openreview.net/forum?id=Q7G74v5nSs

Authors: Qin Guo and Dan Xu (corresponding author), HKUST.

The page directly adapts the authors' WildActor research-project template: https://wildactor.github.io/ . Bulma 0.9.4 and template fonts are bundled for reliable loading. No build step is required.

Content includes original teaser images, six qualitative comparisons from supplied evaluation materials, the manuscript abstract and method figure, and Table 1 of the manuscript. The Code button is intentionally disabled until a repository URL is provided. There is no camera-ready/poster review-download panel. Images open in full resolution; BibTeX can be copied.
